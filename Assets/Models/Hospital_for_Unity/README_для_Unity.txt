БОЛЬНИЦА — ИНСТРУКЦИЯ ДЛЯ UNITY
==================================

ЧТО В ПАПКЕ
  Hospital.fbx  — вся больница (3 этажа + крыша), текстуры вшиты внутрь
  Textures\     — те же текстуры отдельно (на всякий случай)

Масштаб: 1 юнит = 1 метр. Высота этажа 3.698 м.


1. ИМПОРТ
---------
1) Перетащи всю папку Hospital_for_Unity в Assets.
2) Кликни Hospital.fbx -> Inspector:
   Model:     Scale Factor 1, галка Generate Colliders (стены/полы станут твёрдыми)
   Rig:       Animation Type = None
   Animation: Import Animation — выключить
   Materials: Location = Use External Materials (Legacy) -> Apply
              (или кнопка Extract Materials -> выбрать папку Materials)
3) Перетащи Hospital.fbx на сцену. Позицию 0,0,0 не трогай.
4) Объект больницы отметь Static (справа сверху в Inspector) — для света и навигации.
   ВАЖНО: двери и двери лифта потом сними со Static, они двигаются.


2. ЧТО ЕСТЬ ЧТО (иерархия)
---------------------------
Floor_1 / Floor_2 / Floor_3 — пустышки-этажи, внутри всё, что на этом этаже.
Roof        — крыша.
ЗАЛУУУПА    — закрытое крыло снаружи (просто коробка-фасад, внутрь не зайти).

Префикс F1_ / F2_ / F3_ = номер этажа.

ДВЕРИ
  F?_Door_XX            — обычные двери в палаты (одностворчатые).
  F?_SwingDoor_0X_L / _R — двойные маятниковые двери между крыльями.
                           Открываются в обе стороны, когда через них проходишь
                           (без ручки, от толчка игрока).
  F1_DoubleDoor_01_L/_R — двойная боковая дверь 1 этажа.
  F1_MainDoor_01/02_L/_R — главный вход (две двойные двери).
  F?_FakeDoor_01        — ФАЛЬШИВЫЕ двери-заглушки в конце коридора. Не открываются.

  Точка вращения (pivot) у каждой двери уже стоит НА ПЕТЛЕ.
  Значит, чтобы открыть — просто крути её по оси Y на 90° (или -90°).
  Как сделать:
   - обычная дверь: скрипт по кнопке E -> плавно rotate Y 0 -> 90.
   - маятниковая: Box Collider (Is Trigger) по обе стороны; поворачивать
     в сторону ОТ игрока (смотреть, с какой стороны он зашёл), потом сама закрывается.
   - фальшивая: Box Collider, при нажатии E — звук "заперто" / надпись.
  Каждой двери добавь Box Collider (Generate Colliders даёт меш-коллайдер,
  его на дверях лучше заменить на Box).

ЛИФТЫ (на каждом этаже F?_Lift — пустышка, внутри части)
  F?_LiftDoor_L / _R   — створки, едут в стороны (по локальной оси X), не вращаются.
  LiftFront_L/R/Top, LiftFrame_* — рамка/стена вокруг створок.
  LiftCeiling, LiftCeilingLamp   — потолок кабины и лампа.
  LiftDisplay                    — табло с этажом (сюда можно TextMeshPro).
  LiftCallPanel, LiftCallButton  — кнопка вызова снаружи.
  LiftPanel, LiftPanelButton_1..3 — панель в кабине, кнопки этажей 1/2/3.
  F?_LiftSpawn         — пустышка: точка, куда ставить игрока при приезде на этаж.
  Идея: нажал кнопку -> затемнение -> телепорт на F?_LiftSpawn нужного этажа.

ЛАМПЫ
  F?_CeilingLamps — лампы в коридорах (21 на этаж).
  F?_RoomLamps    — круглые лампы по центру палат.
  Это только модельки. Свет добавь сам: Point Light (или Spot вниз) чуть ниже
  каждой лампы. Много — не надо, для хоррора лучше часть выключить или мигать.
  Для производительности: свет Baked/Mixed + Bake Lighting.

КОМНАТА 313
  "Комната 313" и "заглушка для комнаты 313" (3 этаж) — секретная комната
  и стена, которая её закрывает. Заглушку можно выключать/убирать скриптом,
  когда по сюжету комната открывается. Секретной двери пока НЕТ, будет позже.

ФАСАД — снаружи здание покрашено в материал Facade, внутри своё.

4. ЕСЛИ ЧТО-ТО НЕ ТАК
--------------------
- Здание лежит на боку -> в Inspector FBX галка Bake Axis Conversion.
- Падаешь сквозь пол -> не стоит Generate Colliders.
- Дверь крутится не от петли -> вращай саму дверь, а не родителя.
- Мальчик (Boy.fbx) — отдельная папка Boy_for_Unity, там свой README.
