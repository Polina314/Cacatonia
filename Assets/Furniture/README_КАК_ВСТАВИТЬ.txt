МЕБЕЛЬ ДЛЯ БОЛЬНИЦЫ — ИНСТРУКЦИЯ ДЛЯ UNITY 2022.3 (Built-in Render Pipeline, шейдер Standard, НЕ URP)
=========================================================================================================

ЧТО В АРХИВЕ
  Models\    52 модели .fbx. Текстуры вшиты внутрь каждого файла.
  Scripts\   Drawer.cs — выдвижные ящики стола, CabinetDoor.cs — дверцы шкафа и щитка, ElectricLever.cs — рубильник.
  У каждой модели 1 материал и 1 текстура (256x256, у крупных 512x512).
  Всего 16008 треугольников на все модели вместе — для игры это очень мало.
  Масштаб: 1 единица Unity = 1 метр. Точка опоры у всех моделей внизу по центру (кроме халата и настенной вешалки, см. список).


1. ИМПОРТ
-------------------------------------------------
  1) В окне Project создать папку Assets/Furniture и перетащить в неё папки Models и Scripts.
  2) Выделить ВСЕ .fbx в Assets/Furniture/Models (клик по первому, Shift+клик по последнему) -> в Inspector:

     вкладка Model:
       Scale Factor = 1
       Convert Units = галка
       Generate Colliders = БЕЗ галки (коллайдеры ставим вручную, см. пункт 4)
       Generate Lightmap UVs = ГАЛКА (нужно для запекания света, см. пункт 7)
     вкладка Rig:
       Animation Type = None
     вкладка Animation:
       Import Animation = БЕЗ галки
     вкладка Materials:
       Material Creation Mode = Standard
       Location = Use Embedded Materials
     -> нажать Apply.

  3) Там же во вкладке Materials нажать:
       Extract Textures...  -> выбрать папку Assets/Furniture/Textures (создать)
       Extract Materials... -> выбрать папку Assets/Furniture/Materials (создать)
     После этого текстуры и материалы — отдельные файлы, их можно настраивать.
  4) Если какая-то модель белая: открыть её материал в Assets/Furniture/Materials
     и перетащить нужную текстуру из Assets/Furniture/Textures в поле Albedo.


2. ВИД КАК НА PS2
-------------------------------------------------
  Выделить все текстуры в Assets/Furniture/Textures -> Inspector:
    Filter Mode = Point (no filter)
    Compression = None
  -> Apply.
  Особенно важно для Shelves_Documents и Shelves_Documents_Long (наклейки на папках станут чёткими).
  В материалах Smoothness лучше поставить 0–0.1, чтобы мебель не блестела.


3. РАССТАНОВКА
-------------------------------------------------
  - Модели ставятся прямо на пол (Y пола).
  - Toilet, Sink, Shower, шкафы и стеллажи — задней стороной к стене.
  - Phone_Rotary — на рабочий стол поста/регистратуры (Y = пол + 0.765).
  - Coat_Medical (халат) — точка опоры у воротника, ставится прямо на крючок вешалки.
  - Coat_Rack_Wall — точка опоры на полу, ставить вплотную к стене, крючки сами окажутся на 1.6 м.
  - Сгоревшие вещи (*_Burned) — только для палаты 313.
  - Всё, что не двигается, отметить галкой Static (справа вверху Inspector).
    Unity объединит отрисовку, и это заметно облегчит игру.
    ВАЖНО: столу Desk_Metal и шкафу Wardrobe Static ставить только на сам корпус,
    НЕ на ящики и дверцы (иначе они не будут двигаться).


4. КОЛЛАЙДЕРЫ И NAVMESH
-------------------------------------------------
  - Крупная мебель (кровати, шкафы, столы, стойки, стеллажи, ванна, душ, вешалки):
    Add Component -> Box Collider. Он быстрее, чем Mesh Collider.
  - Мелочь (телефон, бутылка, аптечка, пожарная кнопка, табличка, халат): коллайдер не нужен.
  - Ящики и дверцы: Box Collider добавится сам, когда повесите скрипт.
  - После расстановки мебели перепечь NavMesh: выделить объект с компонентом NavMesh Surface
    (пакет AI Navigation) -> Bake. Тогда монстр будет обходить мебель.


5. СТОЛ С ЯЩИКАМИ (Desk_Metal) — скрипт Scripts/Drawer.cs
-------------------------------------------------
  Ящики Drawer_L1..L3, Drawer_R1..R3 и лотки Tray_L, Tray_R — дочерние объекты стола.
  1) Повесить Drawer.cs на каждый ящик и лоток.
  2) Play -> подойти, посмотреть на ящик, нажать E.
  3) Если ящик уезжает ВНУТРЬ стола — у всех ящиков Open Offset Z поменять с 0.3 на -0.3.
  4) Если есть своя система взаимодействия (как у дверей) — снять галку Use Own Input
     и вызывать drawer.Toggle().


6. ШКАФ С ДВЕРЦАМИ (Wardrobe) — скрипт Scripts/CabinetDoor.cs
-------------------------------------------------
  Дверцы (шкаф дверь левая / правая) — дочерние объекты, точка вращения на петле.
  1) Повесить CabinetDoor.cs на каждую дверцу.
  2) Open Angle: у левой 100, у правой -100. Если дверца уходит внутрь шкафа — поменять знак.
  3) Галка Locked — дверца заперта, пока не вызвать Unlock() (например, игрок нашёл ключ).


7. СВЕТ (чтобы игра не тормозила)
-------------------------------------------------
  - Мебель с галкой Static + Generate Lightmap UVs (пункт 1) можно запекать.
  - Обычные лампы: Light -> Mode = Baked. Потом Window -> Rendering -> Lighting -> Generate Lighting.
  - Мигающие лампы запечь нельзя: Mode = Realtime, но Shadow Type = No Shadows и маленький Range.
  - Фонарик игрока — Realtime.


8. ЕСЛИ СКРИПТЫ РУГАЮТСЯ НА Input
-------------------------------------------------
  Скрипты используют старое управление (Input.GetKeyDown). В новом проекте 2022.3 оно включено по умолчанию.
  Если в проекте стоит только новая Input System:
    Edit -> Project Settings -> Player -> Other Settings -> Active Input Handling = Both
  (Unity перезапустится). Или снять Use Own Input и вызывать Toggle() из своей системы.


9. ЭЛЕКТРОЩИТОК (Electric_Panel) — Scripts/ElectricLever.cs и CabinetDoor.cs
-------------------------------------------------
  Дверца щитка (дверца щитка) — дочерний объект, петля слева: повесить CabinetDoor.cs, Open Angle = 110
  (если открывается внутрь — -110). Можно поставить Locked и отпирать ключом.
  Рычаг (рубильник) — дочерний объект: повесить ElectricLever.cs.
    Смотришь на ручку + E -> рычаг опускается/поднимается.
    В On Turned Off / On Turned On подключить что угодно, например выключение света на этаже
    (перетащить объект с лампами и выбрать GameObject.SetActive).
    Если рычаг крутится не в ту сторону — поменять знак Angle (-150 -> 150).
  Static ставить только на корпус щитка, не на дверцу и рычаг.
